# Agent Footprint

防止编程代理把磁盘塞满，避免反复下载测试资源。

[English](README.md)

编程代理每个任务都重复同样的步骤：每轮 QA 新建一台模拟器，每个任务新建一个构建目录，每次测试留一个带时间戳的结果包，再存一组截图。单看都不大，乘以几百个任务就不一样了。在一台 1TB 的 Mac 上，代理留下了约 100GB 模拟器、约 120GB 按任务保存的 QA 证据、重复的构建目录，以及 45GB 它们自己的会话数据。一次清理腾出了 200GB 以上；之后靠几条常驻规则没有再堆起来：再没有按任务新建并留下的模拟器，其中一个代理一周用到的构建目录从 39 个降到 3 个。

这不是某一个代理独有的问题。那台机器上两个不同代理的会话记录显示，两者都新建过带日期的 QA 模拟器、按任务新建过构建目录、留下过带时间戳的测试结果包。不同代理的差别在于各自的数据：有的会话记录没有任何保留期限。

## 提供什么

- **常驻规则**：放进 `AGENTS.md` 或 `CLAUDE.md`。复用固定的测试机和构建目录；任务产物默认是临时的；同类输出只留一份；不动共享缓存和运行时；报告遗留。
- **任务指引**：任务用到模拟器、构建、测试结果、截图或工作区副本时加载。
- **只读体检**（[scripts/audit.py](scripts/audit.py)，macOS）：列出模拟器及其最后使用时间和大小、DerivedData、测试结果包、构建目录、长期不用的依赖、工作区副本、临时目录遗留、代理会话数据和共享缓存。
- **清理流程**：给结果分类，说明每项删除的后果，把文件移进废纸篓，不可恢复的步骤留给你确认。

各平台说明涵盖 Apple 模拟器与 Xcode、包管理缓存、Docker、测试浏览器、Android 模拟器，以及 Codex 和 Claude Code 自己保存的数据。

## 安装

1. 把整个文件夹放到代理加载 skill 的位置，例如 Codex 用 `~/.codex/skills/agent-footprint`，Claude Code 用 `~/.claude/skills/agent-footprint`。不支持 skill 的代理可以直接读 [SKILL.md](SKILL.md)。
2. 加上常驻规则。skill 只在任务看起来相关时才加载，而遗留是在日常任务中堆起来的，所以规则要放在代理每次都会读的说明文件里。发送[设置提示词](prompts/install.zh-CN.md)：代理会按你的测试机和构建目录填好规则块，经你同意后才修改文件。

## 使用

- **体检与清理**：发送[体检提示词](prompts/audit.zh-CN.md)，或自己运行 `python3 scripts/audit.py`（`--quick` 跳过项目扫描，`--caches` 同时统计共享缓存）。
- **日常**：大部分工作靠常驻规则；任务涉及模拟器、构建或测试证据时，skill 补充具体做法。

## 安全

- 体检只读，不删除、不移动、不修改任何东西，也不跟随符号链接。
- 清理在你确认后把文件移进废纸篓。删除模拟器、清理缓存和清空废纸篓都不可恢复，需要单独确认。
- 除非你要求，不动运行时、共享缓存、发布档案、Git 资料和你的文档。
- skill 不会自行安装，未经同意不修改说明文件，也不授权推送或发布。

## 运行要求

体检脚本需要 macOS、Python 3.9 及以上，查看模拟器详情需要 Xcode。规则和指引适用于任何平台。
