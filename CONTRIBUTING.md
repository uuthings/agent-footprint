# Feedback and contributions

The upstream repository is maintained by its maintainers and does not accept pull requests. When Issues are enabled, you may report problems or suggest improvements there. Forking and adapting the skill remain permitted under the MIT License.

Use synthetic examples. Do not include audit output from your machine, private paths, project names, device identifiers, credentials, or unpublished code in reports.

Maintainers keep the audit read-only, keep English and Chinese prompts and rule blocks consistent, and run `python3 scripts/check_public.py` before sharing changes, reviewing actual outgoing Git content separately.
